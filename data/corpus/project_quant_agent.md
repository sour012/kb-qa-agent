# 量化交易 Agent 项目说明

## 系统组成

项目由五个职责单一的 Agent 加一个决策层组成：数据采集 Agent 负责拉取并校验行情与宏观数据；技术分析 Agent 输出趋势与量价信号；新闻情绪 Agent 对财经快讯做情绪打分；宏观贸易 Agent 处理进出口同比与汇率；风险管理 Agent 计算波动率并给出仓位预算上限。

决策层不做黑盒打分，而是把方向层三个 Agent 的分数加权合成，再乘以风险层给出的仓位上限，最后按确认天数与调仓带过滤，输出买入、卖出、持有三类信号，并记录每一条的归因。

## 回测与结论

回测采用 T+1 开盘成交，计入万分之三佣金与万分之五滑点，仓位按 100 份整数倍取整，训练与回测严格按时间切分，不存在未来函数。

因子检验脚本显示：在测试区间内，20 日动量、乖离率、MA20 斜率与未来 20 日收益的 IC 均为负值（-0.03 到 -0.07），说明该区间动量是反向因子。因此顺势策略跑不赢基准是结构性的，而不是参数没调好。

结论写在报告里而不是藏起来：最大回撤从基准的 -24% 压到 -14%，风控模块有效；累计收益略低于基准，策略逻辑需要换成反转或波动率突破，而不是继续调参。

## 技术选型

数据落 SQLite，同时兼容 MySQL，SQL 全部参数化；索引与回测全部用 pandas 与 numpy，不引入重型框架；单测覆盖无未来函数、T+1 成交、两次回测结果逐点一致三条关键不变量。
